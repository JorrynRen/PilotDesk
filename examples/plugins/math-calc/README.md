# 数学计算（math-calc）

工作流节点插件：把常见数学计算做成可直接编排的节点，另外带一个**试算面板**。

## 提供的命令

| 命令 | 用途 | 关键参数 |
|------|------|---------|
| `math.binary` | 二元运算 | `a`、`op` = `add` 相加 / `sub` 相减 / `mul` 相乘 / `div` 相除 / `mod` 取余 / `pow` 求幂、`b` |
| `math.unary` | 一元运算 | `value`、`op` = `abs` / `neg` / `round` / `floor` / `ceil` / `sqrt` / `ln` / `log10` / `exp` |
| `math.aggregate` | 聚合统计 | `numbers`（逗号/空格/换行分隔，或上游输出的数组）、`op` = `sum` / `avg` / `min` / `max` / `median` / `count` / `product` |
| `math.trigonometry` | 三角函数 | `op` = `sin` / `cos` / `tan` / `asin` / `acos` / `atan`、`value`、`unit` = `rad` 弧度 / `deg` 角度 |
| `math.round` | 按位四舍五入 | `value`、`digits`（0~15，默认 2） |
| `math.percentage` | 百分比 | `value`（部分）、`total`（总量） |
| `math.factorial` | 阶乘 | `n`（0~170 的整数） |
| `math.gcd_lcm` | 最大公约数 / 最小公倍数 | `a`、`op` = `gcd` / `lcm`、`b`（均为整数） |
| `math.clamp` | 区间限制 | `value`、`min`、`max` |

## 输出是裸值

**所有命令的产出都是一个数字，不是 `{ result: ... }` 这类包装对象。**

这样下游节点直接引用该节点的输出就是那个数字本身，**不需要再多做一层字段提取**（不用写 `result`、`percent` 之类的后缀）。试算面板同样直接显示裸值。

- `math.percentage` 返回的是**百分数**（如 `74` 表示 74%）；要小数占比就再接一个「二元运算 ÷ 100」。
- 其余命令返回的就是表里那个结果本身。

## 怎么用

**在工作流里**：新增节点 → 选「**插件**」→ 选「数学计算」→ 选命令。
参数表单由平台按 manifest 的 `input` 模式自动生成；参数可填字面量，也可引用上游节点输出（写 `{{字段名}}`）。

因为输出是裸值，`math.binary` → `math.round` → `math.binary` 这样串起来不需要任何中间提取节点。

**试算**：进入会话模式 → 右侧面板 → 「**插件**」标签页 → 「数学计算 · 测试」。
面板里选命令、填参数、点「计算」即可 —— 面板与工作流调用的是**同一批 handler**，面板里算得对，工作流里就算得对。

插件安装与启停在 **设置 › 插件管理**。

## 权限

只声明 `ui:panel`（注册试算面板）。
**不访问网络、不读写文件、不执行命令**，没有任何高风险权限。

## 行为约定（值得知道的几个细节）

- **模板未替换会报错，而不是算成 0/NaN**：若参数写的是 `{{字段名}}` 而上游没有输出该字段，命令会明确报「仍是未替换的模板变量『{{字段名}}』」，不会给你一个看起来"成功"的错误结果。
- **越界输入一律报错而不是返回 `Infinity`/`NaN`**：除零、负数开方、对数非正数、指数溢出、`asin`/`acos` 的入参超出 -1~1、`min > max`、非整数传给阶乘或 gcd/lcm。
- **`tan` 在 90° + k·180° 处报错**：JS 里 `Math.tan(Math.PI/2)` 不会返回 `Infinity`，而是一个约 1.6e16 的浮点数；这里直接拦掉并提示无定义。
- **自动抹掉浮点毛刺**：`0.1 + 0.2` 返回 `0.3`（不是 `0.30000000000000004`），结果保留 10 位小数。
- **三角函数的角度单位语义**：`sin`/`cos`/`tan` 按 `unit` 解释**输入**；`asin`/`acos`/`atan` 按 `unit` 返回**结果**（默认 `rad`）。
- `math.factorial` 的 `n` 上限 170（再大就超出双精度有意义范围）。
- `math.gcd_lcm` 对 `a`/`b` 取绝对值（符号不影响结果）；两者同时为 0 时报错。
- `math.aggregate` 的 `median` 对偶数个元素取中间两个的平均值；`product` 项数超过 200 会拒绝（易溢出）。

## 图标

本插件**未提供图标**，插件列表里会显示默认的 📦。想换成自己的图标：放一张 PNG 进插件目录，
然后在 `manifest.json` 的 `contributes.panels[].icon` 里写相对路径（如 `"favicon.png"`）或网络图片地址。
