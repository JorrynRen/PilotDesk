# Snippet Manager

管理常用文本片段和提示词模板：保存、搜索、复制，随手取用。

## 用途

- 把反复要写的提示词/文本存成片段，用的时候一键复制
- 面板里直接搜索、编辑、删除

## 怎么用

1. 进入**会话模式** → 打开**右侧面板** → 切到「**插件**」标签页
   （终端模式下不显示该标签页；插件需处于「已启用」）
2. 面板标题栏就是 `Snippets`，直接在下面新增/搜索/复制片段
3. 安装与启停不在会话里：**设置 › 插件管理**

## 权限

| 权限 | 用途 |
|------|------|
| `ui:panel` | 在右侧面板注册 `Snippets` 面板 |
| `ui:toast` | 操作反馈通知（**默认授权**，无需声明） |
| `storage:*` | 片段数据存到本插件自己的存储里（**默认授权**，无需声明） |

本插件**不访问网络、不读写插件目录以外的文件、不执行命令**，也不声明任何高风险权限。

片段数据只落在插件自己的 `api.storage` 命名空间下；卸载插件会一并清掉（需要长期保存的内容请自行留档）。

## 已知限制

- 复制依赖 `navigator.clipboard.writeText`（平台给插件的最小只读 `navigator` 替身只放行了这一项）
- 面板里自建的输入框**没有** `{{变量}}` 补全 —— 那是工作流参数表单（`props.TemplateField`）的能力；本插件不向工作流暴露命令，所以不涉及
